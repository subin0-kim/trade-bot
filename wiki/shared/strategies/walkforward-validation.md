# 워크포워드 검증 — 선택 편향 제거

## 왜 필요했나

전 구간에 여러 전략을 돌려 최고를 고르면, 그 성적은 **선택 편향**에 오염된다.
코인 검증에서 50조합 중 유일한 플러스(`breakout_momo@240m` +7.19%)가
전후반 분할에서 재현 실패한 것이 결정적 계기 ([[crypto-backtest-round1]]).

## 설계

```
|---- IS 1000봉 ----|- OOS 350봉 -|
          |---- IS 1000봉 ----|- OOS 350봉 -|
                    |---- IS 1000봉 ----|- OOS 350봉 -|
```

- **IS(In-Sample)에서만 전략을 선택**하고, **OOS에서 측정**한다
- OOS는 선택에 쓰이지 않았으므로 편향 없음 — 이것만이 정직한 추정치
- OOS 수익 산출: 전체(IS+OOS) 누적수익에서 IS 누적수익을 복리로 제거

## 진단 지표 (편향을 드러내는 장치)

| 지표 | 의미 |
|---|---|
| **과적합 격차 (IS − OOS)** | 클수록 IS 성적이 허상 |
| **선택 안정성** | 폴드마다 같은 전략이 뽑히는 비율. 낮으면 신호가 아니라 잡음을 쫓는 중 |
| **선택 분포** | 여러 전략에 흩어지면 안정적 우위가 없다는 뜻 |

## 코인 검증 결과 (240분봉, 2026-07-27)

가설: "알트는 구조적으로 불리하고 메이저(BTC/ETH)는 다를 것"

| | 메이저 7종목 | 알트 19종목 |
|---|---|---|
| IS 중앙수익 | +4.77% | +3.87% |
| **OOS 중앙수익** | **-0.47%** | **-0.78%** |
| 과적합 격차 | 3.94%p | 4.15%p |
| OOS 수익 종목 | 2/7 | 4/19 |
| 선택 안정성 | **25%** | 57% |
| 선택 분포 | 5개 전략에 분산 | 9개 전략에 분산 |

**가설 기각**: 메이저(-0.47%)와 알트(-0.78%)의 OOS 성과 차이가 미미하다.
메이저라고 유의하게 낫지 않다. 오히려 **선택 안정성은 메이저가 25%로 더 낮다**
(폴드마다 다른 전략이 최고로 뽑힘 = 안정적 우위 부재).

**공통 관측**: IS +4%대가 OOS에서 -0.5% 전후로 붕괴. 과적합 격차 약 4%p.
즉 **지금까지 본 코인 백테스트의 플러스 성과는 대부분 선택 편향의 산물**이었다.

## 결론

- 현재 전략 풀(9종)로는 **코인에서 편향 없는 우위를 찾지 못했다**. 메이저·알트 모두 해당
- 이 결과는 "코인은 안 된다"가 아니라 **"이 전략 풀·이 기간·이 방법으로는 안 된다"**
- 향후 어떤 전략을 채택하든 이 프레임을 통과해야 한다. 전 구간 최고 성적은 근거가 아니다

## 주식에도 적용 필요

주식 챔피언(현금/connors/macd, +44.1%)도 매핑 조합 10여 개에서 사후 선택한 것이다.
같은 프레임으로 재검증하지 않은 상태 — **다음 과제**.
